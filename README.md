# Cinder Ward

Public-safe coordination repository for a commercial dark-fantasy 2D/2.5D Steam game prototype.

This repository starts with process, research summaries, task split, and review protocol only. It intentionally does not include private keys, Steam partner data, paid API outputs, unverified generated assets, or unlicensed reference media.

## Current Direction

- Camera: top-down or isometric 2D/2.5D.
- Tone: dark fantasy with readable action, strong silhouette, high-contrast light, and dynamic pressure.
- Engine: not locked. Godot, Unity, and Unreal are being evaluated against the first vertical slice.
- Gameplay: no fixed countdown timer. Tension should come from enemy pressure, state deterioration, resource tradeoffs, and readable consequences.
- Art: no generic JRPG hero. The first milestone is one commercially convincing protagonist on screen.

## Public Safety Rule

If a file cannot be publicly shown to a Steam audience, a contractor, and GitHub history forever, it does not belong in this repository.
