# Publication Policy

This repository is public. Treat every commit, pull request, issue, action log, and deleted file as permanent.

## Allowed

- Public-safe summaries of market research.
- Original design decisions that do not disclose private business data.
- Engine and tool evaluations.
- Source code after license and package review.
- Original assets only after source, license, and approval notes exist.

## Not Allowed

- API keys, tokens, cookies, credentials, signing certificates, private keys.
- Steam partner data, depot data, app secrets, unpublished revenue or contract data.
- Paid API generation outputs without explicit public release approval.
- Unverified AI outputs, prompts containing secrets, or model responses containing private material.
- Third-party images, videos, music, fonts, or game assets unless the exact license allows public redistribution.
- Existing local prototype artifacts until they pass asset intake.

## Current Rule For Research Media

Steam screenshots, YouTube frames, music references, and benchmark material may be summarized but not committed as media files unless redistribution rights are verified.
