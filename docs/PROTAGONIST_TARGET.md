# Issue #3: 主人公 96px/48px ターゲット仕様

日付: 2026-06-29  
ブランチ: `codex/art-protagonist-target`

## 1) 成功条件

- 主人公は**「若い灰まみれの巡礼剣士」**として一目で判別できること  
  - 折れた戦旗を背負う
  - 低い短剣（または短い剣）
  - 小さな丸盾
  - 破れた深い青の外套、灰で汚れた白い下衣、くすんだ赤スカーフ
  - 錆びた鉄・古い真鍮・worn leather の素材感が読み取れること
  - 顔は見えるが顔全体が巨大化しないこと（大きなアニメ顔禁止）
- 2D-HD商用品質として、96px版を起点に、48px版へ縮小して**重さ・疲労・畏怖**の印象が維持されること
- 遊び中の可読性が高く、体幹位置、武器配置、盾配置のシルエットが崩れないこと
- ベルトアクション（主動作を帯状移動で継続的に回避・回転中心でごまかす演出）は導入しないこと
- 固定時間制限（30秒カウントダウン等）を戦闘進行に固定制約として使わないこと
- Steam向け商用品質に必要な理由で、既存IP・固有意匠の模倣やトレース表現を含めないこと
- Maya/Blender/Mixamo等の3D下地は**参照用途のみ**とし、最終提出物は**独自2D-HDピクセル**であること
- Maya付属素材など商用利用ライセンスが未確認のものは、本番資産として採用しないこと

## 2) 拒否条件

- v6/v7ローカル試作のように、**チビッぽく重量感が不足**したデザイン
- 48px時点で体格・武器・盾の識別が困難になること
- 肌・目・髪の過度な誇張で、キャラが「アニメ顔寄り」になっていること
- ベルトや尻尾のような継続的回避系ムーブで重さを偽装すること
- 既存ゲームの明確なコスチューム・ポーズ・武器形状を模写していること
- 暗背景で輪郭が埋没し、前景判別が崩れること

## 3) 96px/48pxシルエット仕様

- **基準キャンバス**  
  - 96px版: 1フレームを `96 x 96`（または同アスペクトの余白調整可）  
  - 48px版: 96px版を1/2縮小し、主要判別要素（旗・剣・盾・首飾り帯状）を維持
- **高さ・プロポーション**  
  - 96px版: 体高は70〜78px、頭部は18〜22px  
  - 48px版: 頭部は9〜11px程度、武器先端は脚上部より高くならない
- **シルエット優先ルール**  
  1. 腕と武器が独立シルエットに見えること  
  2. 外套の裾と旗の先端が視線誘導になること  
  3. 小さな丸盾は明るい縁取りか、濃度反転で輪郭が確保されること
- **色域**  
  - メイン暗色： #1A1F2A / #2A3546 / #33415A  
  - サブ：古い白：#D6D1C7、汚れ赤：#7A4231、金属：#6D6252〜#A09177
- **アニメ/PIE(ポリシー)注意**  
  - 顔面は2〜4px幅程度で形状をまとめ、目・髪・口角で性別を決める方向に寄せる
  - 顔面比率を過度に崩さず、体格バランスで“重さ”を担保する

## 4) Idle / Move / Attack / Hurt

### Idle
- 4〜6コマ、3〜4秒以内でループ  
- 呼吸、肩の沈み、盾や旗のわずかな揺れを含める  
- 毎秒2〜3px以内の上下差で「静止した重さ」を表現

### Move
- 6〜8コマ  
- 1歩あたり: 重い接地 → 推進 → 体幹戻し → 次の足運び  
- 接地フレームで最低1フレーム停滞を作り、急加速より慣性を表現

### Attack
- 8〜10コマ、開始5〜7fで溜め、3〜4fでヒットの実感、余韻2〜3f  
- 斬撃の軌道は短い剣のため接近戦中心、体重移動を強調  
- 振り抜き後の回復が1f以上あることで無理な連射を抑止

### Hurt
- 5〜7コマ  
- 1フレーム目はノックバック（後退）、2〜3フレーム目で沈み込み、4フレーム目でバランス回復  
- 長期無敵を作らず、次アクションとの間に短い隙間を確保

## 5) 暗背景検証

- 背景として以下を想定し、読みやすさを最終判定  
  1. 暗灰: `#07080C`  
  2. 深青: `#101726`  
  3. コバルト黒寄り: `#0B111A`
- 検証観点（48/96両サイズ）
  - 旗端、剣先端、円盾縁の3点が背景に対して認識可能であること
  - 斜め背景でもシルエットを外骨格で追えること
  - 影・輪郭の濃度差が1段階以上分離していること
- 合格条件: 3色背景すべてで、2秒以内に主従（体の向き・武器手元・盾側）を判別できること

## 6) Maya/Blender下地手順

1. **リサーチ資産準備**  
   - ライセンス確認済み素材のみ使用（例: Mixamo商用可、Poly Haven CC0）  
   - 未確認素材は採用不可、候補は外部メモに保留
2. **Blender/Mayaでブロックアウト**  
   - 体型比率（体高/腰/肩幅）と重心位置を先に確定  
   - 旗・外套・盾を含む全体3体積の占有を確認
3. **角度確認**  
   - 2D_HD向けは主に側面〜斜め三分の二角度を確認  
   - 96px表示時の形崩れ確認、48pxでの主要パーツ可視性を同時確認
4. **カメラ/パース記録**  
   - パース設定、FOV、カメラ高さ、ライト比率を記録  
   - 2.5Dっぽさを残す参照として参照画像とノートを残す
5. **2D化**  
   - 3D下地をトレース/改変してピクセル化（輪郭は再設計可）  
   - 既存IPの再現にならないよう、意匠は必ず差分を付ける（破損位置・比率・模様）
