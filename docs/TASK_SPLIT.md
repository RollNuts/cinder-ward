# Task Split

The project should move through small PRs. veripsa core should be asked to split any PR that mixes unrelated decisions, code, and assets.

## Initial Tracks

1. `repo: public safety baseline`
   - Branch protection.
   - Secret scan.
   - Public/private boundary.

2. `research: sellable visual benchmark`
   - Steam screenshots.
   - Official trailers.
   - Audio/OST references.
   - No copied media in repo.

3. `design: strong protagonist one-body target`
   - Reject generic JRPG hero.
   - Define one strong silhouette at 96px.
   - Define Idle/Move/Attack/Hurt.

4. `engine: vertical slice decision`
   - Godot, Unity, Unreal comparison.
   - Hands-on camera/lighting/2D-character test.
   - Steam build path.

5. `gameplay: no fixed timer pressure model`
   - No countdown-driven design.
   - Use enemy pressure, state deterioration, resource safety, and consequences.

6. `pipeline: Aseprite / PixelOver / Blender / DCC`
   - Sprite workflow.
   - 2.5D room workflow.
   - Commercial license notes.

7. `prototype: first 30 seconds`
   - One room.
   - One protagonist.
   - One dynamic threat.
   - One satisfying action loop.

## Split Rule

If a task changes more than one of repo policy, engine, gameplay, art, audio, or build pipeline, split it.
