# AI Asset Policy

AI tools may be used only when the usage is deliberate, logged, and legally usable for a commercial Steam release.

## Approval Required Before Paid/API Generation

Before spending paid credits or calling a paid generation API, record:

- Tool/provider.
- Prompt or input category.
- Purpose.
- Success criteria.
- Maximum attempts/credits.
- Failure save path.
- Commercial license and attribution requirements.
- Whether output can be public, private-only, or game-shippable.

## Preservation Rule

Generated assets are never deleted just because they are rejected. Preserve them under an archive/rejected path with notes. Rejected means "not active", not "discarded".

## Public Repo Rule

Do not commit raw paid/API outputs or unreviewed generated assets to this public repository. Use asset intake first.
