# Contributing

This is a commercial game project. Public contributions are not accepted unless explicitly requested.

For internal work:

1. Use small pull requests.
2. Keep one PR focused on one purpose.
3. Do not add assets without source, license, and public-safety notes.
4. Do not add packages, plugins, or SDKs without a short approval note covering license, purpose, alternatives, and removal path.
5. Ask veripsa core for split/risk review in the PR body or comments when scope grows.
